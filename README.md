# Kharche Technologies

A responsive React single-page website built with Bootstrap for Kharche Technologies. Includes sections for home, services, enquiry, gallery, blog, help, team, and contact.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the frontend development server:
   ```bash
   npm start
   ```
3. Run the Spring Boot backend from the `kharchetech` project:
   ```bash
   cd c:\Users\vaibh\Downloads\kharchetech\kharchetech
   mvn spring-boot:run
   ```

## Project structure

- `public/` — static HTML entry
- `src/` — React app source
- `src/components/` — page sections and shared UI
